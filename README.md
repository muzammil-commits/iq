## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/muzammil-commits/iq.git

# Navigate into the project directory
cd iq

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
